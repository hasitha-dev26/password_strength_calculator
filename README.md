# 🛡️ Password Strength & Hash Calculator

A robust and secure Python-based application designed to evaluate password strength using regex validation and generate cryptographic hashes (SHA-256 and MD5) for enhanced security analysis.

---

## 🚀 Features

* **Password Strength Analysis**: Evaluates passwords based on length, lowercase/uppercase letters, numbers, and special characters.
* **Cryptographic Hashing**: Instantly generates secure **SHA-256** and **MD5** hash outputs for any given input.
* **Interactive CLI**: User-friendly command-line interface with clear feedback and recommendations for password improvement.

---

## 🛠️ Tech Stack

* **Language**: Python 3.15.2
* **Libraries**: 
  * `re` (Regular Expressions for pattern matching and validation)
  * `hashlib` (Cryptographic hashing module)
